# VANTA Sovereign — независимый ИИ и собственный поиск

Этот вариант не использует OpenRouter и не требует платить за каждый запрос к стороннему ИИ API. На своём компьютере или GPU-сервере ты запускаешь Ollama и SearXNG. Пользователь владеет исходным кодом, конфигурацией и выбранными весами модели.

ВАЖНО: это свой продукт, но не фундаментальная нейросеть, обученная с нуля. Модель работает только пока включён твой сервер. API-квоты нет, но ограничена скорость вычисления, память и доступ к внешним поисковым системам.

## Запуск на Windows

Нужны: Docker Desktop с WSL2, Python 3. Windows ПК с 8 GB RAM и GTX 1060 6 GB подходит для маленьких моделей (Qwen3 4B ~2.5 GB на диске), но большие модели будут медленными или не поместятся.

1. Скачай GitHub репозиторий anime-void-app/anime-void-app.github.io и открой PowerShell в каталоге vanta/selfhost.
2. Создай .env из .env.example командой ниже:

~~~powershell
Copy-Item .env.example .env
python -c "import secrets;print(secrets.token_urlsafe(40));print(secrets.token_urlsafe(40))"
notepad .env
~~~

3. Вставь два РАЗНЫХ случайных значения из Python в VANTA_ACCESS_TOKEN и SEARXNG_SECRET. Никому их не отправляй. Никогда не добавляй .env в публичный GitHub.
4. Запусти Docker и загрузи начальную модель:

~~~powershell
docker compose up -d --build
docker compose exec ollama ollama pull qwen3:4b
~~~

5. Открой http://127.0.0.1:8765. В настройках VANTA оставь адрес сервера пустым либо введи http://127.0.0.1:8765. Введи VANTA_ACCESS_TOKEN и отправь сообщение. Статус «Свой ИИ доступен» и кнопка «🌐 Поиск» появляются при доступном сервисе.

## Поиск

SearXNG собирает выдачу других поисковиков. VANTA по умолчанию отправляет пользовательский вопрос в SearXNG, добавляет до 10 найденных заголовков/фрагментов в контекст модели и прикладывает URL источников к ответу. Число источников меняется параметром SEARCH_RESULTS в .env (до 20). Кнопкой «🌐 Поиск» можно отключить передачу вопроса поисковикам.

Сам SearXNG не имеет нашего лимита запросов в сутки. Однако сайты и поисковики могут блокировать частые автоматические запросы, результаты бывают неполными. В этой версии поиск анализирует фрагменты выдачи, а не прочитывает полный текст всех сайтов. Для собственного большого индекса и краулера нужна отдельная инфраструктура.

Приватность: веб-поиск всё равно может раскрыть запрос и IP серверов внешним поисковым движкам. Выключай поиск для конфиденциальных вопросов.

## С телефона по приватному HTTPS

Установи Tailscale на ПК и телефон и войди в одну собственную Tailnet. Затем в PowerShell на ПК:

~~~powershell
tailscale serve --bg 8765
tailscale serve status
~~~

Открой адрес HTTPS вида computer.tailnet.ts.net, который покажет Tailscale, с телефона с активным Tailscale. В VANTA введи личный VANTA_ACCESS_TOKEN. Не включай Tailscale Funnel и не пробрасывай порты 8765 или 11434 на роутере.

## Разные мощности

По умолчанию режимы FAST, SMART, DEEP и MAX ведут к одной маленькой модели Qwen3 4B — это честный старт для слабого ПК. На мощном GPU-сервере можешь отдельно настроить MODEL_FAST, MODEL_SMART, MODEL_DEEP и MODEL_MAX в .env, скачать выбранные модели через docker compose exec ollama ollama pull <имя> и перезапустить app.

Пример для значительно более мощного сервера: MODEL_FAST=qwen3:4b, MODEL_SMART=qwen3:8b, MODEL_DEEP=qwen3:30b, MODEL_MAX=qwen3:32b. Эти модели нужно загрузить, а GPU/RAM должны их вместить. Такая конфигурация НЕ установлена автоматически.

Число одновременных генераций MAX_CONCURRENT=1 защищает слабый сервер от перегрузки. Это не лимит сообщений в день.

## Картинки

VANTA Sovereign в этой сборке делает ТЕКСТ и ВЕБ-ПОИСК. Самостоятельная генерация изображений без API требует отдельной модели и GPU-сервера (например ComfyUI). В текущем режиме selfhost эндпоинт /api/images ещё не реализован, не считай Visual Lab готовым к рисованию локально.

## Безопасность и проблемы

- .env содержит секреты и не должен попадать в git.
- VANTA привязан к 127.0.0.1:8765; Ollama и SearXNG доступны только внутри Docker-сети.
- История чатов хранится нешифрованной на устройстве в браузере, кроме сеансового режима.
- Модель и контейнеры нужно запускать на ПК/сервере; сам GitHub Pages Docker не запускает.
- /api/health должен вернуть provider: VANTA Sovereign.
- Ошибка 401 означает неправильный личный токен; ошибка Ollama 404 — модель не загружена.
- Docker проверяется командами docker compose ps и docker compose logs -f app.
