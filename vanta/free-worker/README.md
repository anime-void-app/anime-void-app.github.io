# VANTA Free Cloud — 0 ₽, телефон работает без включённого ПК

Это бесплатный облачный вариант VANTA для владельца, у которого уже есть Cloudflare. Отдельный аккаунт OpenRouter, GPU-сервер и постоянный включённый компьютер не требуются. Используется **Cloudflare Workers AI**.

Состояние: код сервера и интерфейс на GitHub готовы. В аккаунт Cloudflare пользователя сервер ещё НЕ опубликован; для запуска потребуется один раз создать Worker и связать его с Workers AI. Не отправляй никому пароль Cloudflare или секрет VANTA.

## Что бесплатно

- Cloudflare Workers Free включает 10 000 Neurons/сутки для Workers AI. Квота общая для ответов и картинок. По её исчерпании бесплатный режим останавливается до сброса, а не даёт бесконечные запросы. **Не включай Workers Paid и платную unified billing, если бюджет строго 0 ₽.**
- Cloudflare Worker может работать круглосуточно на инфраструктуре Cloudflare. Сам компьютер пользователя выключен.
- Разные режимы FAST = GLM-4.7 Flash, SMART = Gemma 4 26B, DEEP = Qwen 3.8 27B, MAX = та же Qwen 3.8 27B с более длинным ответом. MAX — НЕ отдельная модель и расходует больше квоты при длинных ответах.
- Генерация картинок = FLUX.1 Schnell, только 1:1, с выбором 4 / 6 / 8 шагов. Все варианты используют одну модель и общую квоту Neurons.
- История чатов остаётся локально в браузере; на сервере VANTA не создаётся личная база переписок. Облачная модель обрабатывает запрос, поэтому это **не офлайн-ИИ**.
- Полноценный поиск по всему интернету в версии Free Cloud **не реализован**. Самостоятельный SearXNG находится в отдельной версии selfhost, для которой нужен включённый ПК или сервер.

⚠️ Cloudflare меняет доступность моделей: 20 ноября 2026 года отключены `@cf/qwen/qwen3-30b-a3b-fp8` и `@cf/nvidia/nemotron-3-120b-a12b`, поэтому в этом проекте используются актуальные альтернативы.

## Запустить только с Android — шаги в браузере

1. На телефоне открой https://dash.cloudflare.com/ и войди в свой Cloudflare аккаунт.
2. Открой раздел **Workers & Pages → Create application → Create Worker**. Название можно указать **vanta-ai-free**. Выбери стартовый `Hello World` и создай Worker. В разных версиях Cloudflare названия пунктов меню могут немного отличаться.
3. Открой уже созданный Worker → **Edit code / Quick edit**. Удали стартовый пример и вставь JavaScript из своего GitHub по ссылке ниже. Нажми **Deploy**.

**Исходник для копирования:** https://github.com/anime-void-app/anime-void-app.github.io/blob/main/vanta/free-worker/src/index.js

Чтобы копировать на Android удобнее, открой GitHub-файл и нажми **Raw**, затем выдели весь текст. Копируй только код Worker, не строку JSON из конфигурации.

4. В настройках Worker открой **Bindings → Add binding → Workers AI**. Имя переменной обязательно **AI** (заглавные буквы). Сохрани и заново разверни Worker, если панель попросит.
5. В настройках Worker открой **Variables and Secrets → Add → Secret**. Имя секрета — `VANTA_ACCESS_TOKEN`. Значение — отдельный **случайный пароль длиной минимум 32 символа**, созданный в менеджере паролей на телефоне. Секрет вводится ТОЛЬКО на сайте Cloudflare. Не присылай его в чат, не вставляй в GitHub. Если поле предлагает type, выбери **Secret**, не обычный Text.
6. Cloudflare покажет URL твоего Worker, например `https://vanta-ai-free.XXXX.workers.dev` — `XXXX` у каждого аккаунта индивидуален. **Не копируй пример буквально.**
7. Открой https://anime-void-app.github.io/vanta/ → ⚙ Настройки. Введи СВОЙ URL Worker в поле сервера; ниже введи свой `VANTA_ACCESS_TOKEN` из шага 5. В поле «Свой ID модели» ничего не указывай. Нажми **Сохранить настройки**.
8. Подожди обновления статуса. Должно появиться **«Бесплатный ИИ готов»**. Отправь короткое сообщение в FAST или SMART. Для картинок открой «✧ Фото AI» → выбери FLUX 4 шага и квадрат 1:1.

Официальная инструкция binding: https://developers.cloudflare.com/workers-ai/configuration/bindings/
Официальный лимит Neurons: https://developers.cloudflare.com/workers-ai/platform/pricing/

## Тест и проблемы

- `https://твой-worker.workers.dev/api/health` — публичная проверка готовности; ожидается JSON `provider: VANTA Free`, `configured: true`. Этот URL не требует личного токена и не вызывает платную модель.
- `configured:false` означает, что переменная AI или VANTA_ACCESS_TOKEN (32+ символа) не добавлена правильно.
- `401` — неправильный личный токен.
- `403` — выбрана модель, которая требует Workers Paid или запрещённый origin.
- `429` — превышена бесплатная квота или лимит запросов.
- `502` — модель недоступна или её ответ некорректен; проверь dashboard и доступность конкретной модели.
- Настройки VANTA сохраняют URL в localStorage телефона, а токен — только в оперативной памяти вкладки. После перезагрузки вкладки токен понадобится ввести повторно.
- Если на сайте показывается «Модель не ответила», начни с режима FAST.
- Если хочешь применять командную строку с компьютера, есть `wrangler.json` с AI binding и лимитерами. При ручной установке через Cloudflare Quick Editor rate-limit bindings могут отсутствовать: Worker всё равно защищён случайным токеном, а Workers Free ограничивает общую бесплатную квоту.

## Важное

Это **0 ₽ только в рамках Cloudflare Workers Free**. Нельзя обещать безлимитный 24/7 ИИ одновременно с нулевыми расходами и выключенным ПК. После суточной квоты нужно дождаться её сброса или пользоваться локальной моделью на своём компьютере. Обязательно проверь, что на аккаунте не включён платный Workers или AI Gateway unified billing.

В будущем можно подключить самостоятельный SearXNG, расширенный поиск, память/синхронизацию, бесплатные новые модели и крупный GPU-сервер, когда появится бюджет.
